DepthCAD

Build depth maps for laser engraving by compositing layers. Layers are composited bottom-to-top with a per-pixel max ("Union" mode), so overlapping geometry intersects realistically. Other modes: Clamp (min), Replace, Cut (erase everything below inside the layer), Keep (erase everything below outside the layer). Text layers render any installed font (or a loaded .ttf/.otf/.woff file, which is embedded in the project) and are transformed, masked and blended like any other layer. Masks belong to a layer and move with it. A "keep" mask keeps only the inside of the shape; an "inverted" mask removes the inside. Canvas: drag a layer to move it, drag corner/edge handles to scale (Shift toggles aspect lock, Alt scales about the center), drag the round handle to rotate (Shift snaps to 15°). Wheel or pinch to zoom, drag empty space or hold Space to pan, arrow keys nudge (Shift = 10 px). Shortcuts: Ctrl+Z/Ctrl+Shift+Z undo/redo, Ctrl+D duplicate, Del delete, Ctrl+S save, Ctrl+O open, F fit, 1 100%. 3D view: drag to orbit, wheel to zoom, right-drag / Shift-drag to pan. Projects (.dcad.json) embed the imported images, so a single file is self-contained. The project is also autosaved in this browser.
